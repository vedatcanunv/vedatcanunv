## About Me

Computer Engineering graduate focused on end-to-end product development across mobile, backend, and AI systems.

I build React Native and Expo applications, full-stack web products, and RESTful backends with relational database design. Recent work also includes AI-powered applications — RAG pipelines, multi-agent workflows, and LLM integration — alongside authentication, workflow systems, and cloud deployment.

I approach software as an engineering problem: clear architecture, maintainable code, and systems that hold up beyond the prototype stage.
